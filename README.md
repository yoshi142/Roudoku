# Roudoku

AIが大部分を担う在宅の小さな事業の試行。本人の声で語る音声（文学の朗読、宇宙の話、AIの動向）を作り、公開できる形まで持っていけるかを確かめる。

## 構成

- `narration/trial-NN/` 試行ごとのフォルダ
  - `candidates.md` 候補選びの記録（著作権の確認結果を含む）
  - `script.md` 台本
  - `recording-guide.md` 録音の手引き
  - `publish.md` 公開用の文面（タイトル案、説明文、チャプター）
  - `log.md` 記録（時間、尺、ツールと費用、問題点、次の判断材料）
  - `raw/` 録音の原音（無加工）。Git には入れない
  - `out/` 整音済み音声、動画、サムネイル。Git には入れない
- `tools/` 整音、動画化、サムネイル生成のスクリプト（ffmpeg と Python）

## 方針

- 文学の朗読はパブリックドメインの作品に限る。青空文庫の図書カードに「著作権存続」の表示がないことを確認する
- 録音の原音は無加工のまま別に保存する（将来の音声合成の学習素材になりうるため）
- 音声と動画はリポジトリにコミットしない（`.gitignore`）
