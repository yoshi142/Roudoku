# 伸びている朗読動画の分析　報告

Ver.1.0　分析日：2026-10-23　作成：AI　骨子：docs/analysis/plan.md

## 1　要点

1. “みんなが知っている作品” ほど朗読も見られる。作品の知名度（ウィキペディアの年間閲覧数）と朗読動画の総再生の順位相関は 0.73 だった。ただし、有名な作品ほど大手チャンネルが強い。新しいチャンネルが入り込めるかどうかは別の話になる（4章）。
2. 小さなチャンネル（登録者1万人未満）でも見られている作品は限られる。平家物語・枕草子の冒頭、雨ニモマケズ、銀河鉄道の夜、夢十夜が上位だった。走れメロス、羅生門、ごんぎつね、手袋を買いには、小さなチャンネルの動画の多くが数百回にとどまっていた。
3. 長さは “30分以上” が有利。チャンネルの規模と作品をそろえて比べると、5〜15分の動画に対して、1〜2時間は約2.2倍、2時間以上は約2.8倍の再生だった（登録者10万人未満のチャンネル）。5分未満の短い動画は5〜15分と差がない。
4. タイトルは「【朗読】」で始めないほうがよい。規模をそろえても、【朗読】を付けたタイトルは再生が約0.55〜0.6倍だった。作品名で探される場面では「睡眠・寝落ち」を入れたタイトルも約0.5〜0.6倍だった。
5. サムネイルは “暗すぎない画面に白い太字” が有利。画面の暗い部分が多いほど再生が少なく、白い文字の面積が多いほど多い。色数が少ない簡潔な画面のほうがよい。
6. コメントは【コメントの要点を入れる】
7. 2025〜2026年に急に伸びた動画は、知名度のある出演者（VTuber など）と、「結末」「意味」を知りたい人に向けた動画が中心だった。ふつうの朗読で最近大きく伸びた小さなチャンネルは見当たらなかった。

## 2　調べ方

| 項目 | 内容 |
|------|------|
| 作品 | 青空文庫で読める有名作品・教科書の作品 44作 |
| 動画 | 作品ごとに YouTube で「作品名 作者名 朗読」を検索した上位40本、計1,760件。題名に作品名を含むものに絞り、朗読1,474本、絵本アニメ76本、解説72本などに分けた |
| チャンネル | 動画を出している709チャンネルの登録者数（YouTube の公開情報） |
| 投稿日とコメント | 作品ごとの再生上位12本（計498本）の投稿日。うち上位4本（計153本）の上位コメント20件ずつ |
| 知名度 | 日本語版ウィキペディアの記事閲覧数（2025年10月〜2026年9月の12か月、人による閲覧のみ） |
| 教科書 | 出版社の公式資料、自治体の採択資料などで確認（docs/research/data/textbook_works.csv） |
| 比べ方 | 再生数の対数を、登録者数の対数、作品の違い、長さの区分、タイトルの要素、サムネイルの数値で説明する重回帰分析。チャンネルの規模と作品の人気の影響を取り除いたうえでの「倍率」で示す。大手を除いた範囲（登録者10万人未満、1万人未満）でも同じ傾向が出るかを確かめた |

データは docs/research/data/ に CSV で保存した。手順は tools/yt_research.py と tools/yt_innertube.py。

## 3　観点ごとの結果

### 3-1　みんなが知っているか（知名度）

作品の知名度と朗読動画の再生の順位相関（36作品）

| 比べたもの | 順位相関 |
|------------|----------|
| 朗読動画の総再生（上位40本） | 0.73 |
| 最も再生された1本 | 0.66 |
| 1万回を超えた本数 | 0.69 |
| 登録者1万人未満のチャンネルの動画の再生中央値 | 0.36 |

有名な作品ほど朗読もよく見られる。ただ、小さなチャンネルに限ると関係は弱くなる（0.36）。有名な作品には大手チャンネルの動画がすでにあり、検索の上位をそちらが占めるためと考えられる。

知名度の上位（ウィキペディアの年間閲覧数）：竹取物語 33万、銀河鉄道の夜 31万、平家物語 17万、人間失格 13万、走れメロス 12万、山月記 10万、こころ 10万、徒然草 10万。

### 3-4　動画時間

チャンネルの規模と作品をそろえたときの再生の倍率（5〜15分を1とする）

| 長さ | 全体 | 登録者10万人未満 | 登録者1万人未満 |
|------|------|------------------|----------------|
| 5分未満 | 0.94 | 0.86 | 0.72 |
| 15〜30分 | 1.39 | 1.19 | 1.06 |
| 30〜60分 | 1.48 | 1.56 | 1.12 |
| 1〜2時間 | 1.84 | 2.17 | 1.61 |
| 2時間以上 | 2.17 | 2.79 | 1.18 |

全体と登録者10万人未満では、30分を超えると再生が増える傾向がはっきりしていた（1〜2時間、2時間以上は統計的にも明確）。登録者1万人未満では同じ向きだが、はっきりした差ではなかった。1日あたりの再生（投稿日が取れた動画の中央値）も、5分未満が約11回、15〜30分が約26回、1〜2時間が約83回、2時間以上が約168回と、長いほど多い。長い動画は寝る前や作業中に流され続けるためと考えられる。

一方で、雨ニモマケズや枕草子・平家物語の冒頭のように、数分の短い動画でも小さなチャンネルで見られている作品がある。これらは「暗唱」「覚えたい」という別の需要がある。

### 3-5　サムネイル

チャンネルの規模と作品をそろえたときの、画像の数値1標準偏差あたりの再生の倍率

| 数値 | 倍率 | 読み方 |
|------|------|--------|
| 暗い部分の割合 | 0.64 | 暗い画面ほど再生が少ない |
| 白い文字に当たる部分の割合 | 1.32 | 白い太字の面積が多いほど多い |
| 色数 | 0.85 | 色数が少ない簡潔な画面のほうがよい |
| 彩度 | 1.13 | やや鮮やかなほうがよい（境界的） |
| 明暗の差 | 1.03 | はっきりした差はない |

目視では、前回の調査（docs/thumbnail-research.md）と同じく、AI 生成と見られる劇的な画像（山月記の虎、走れメロスの場面など）は下位に多かった。ただし下位には文字だけの整ったサムネイルも多く、サムネイルだけで差を説明することはできない。

このチャンネルの試作 v2 を同じ数値で見ると、「雨ニモマケズ」は暗い部分が49％で、伸びている動画（上位10％の中央値21％）より暗すぎた。背景を明るくし版画の色を戻した修正版では9％になった（docs/thumbnail/amenimo_v2.jpg を差し替え済み）。

### 3-6　タイトル

チャンネルの規模・作品・長さをそろえたときの再生の倍率（「あり」の「なし」に対する倍率）

| タイトルの要素 | 全体 | 登録者10万人未満 | 登録者1万人未満 | 判断 |
|----------------|------|------------------|----------------|------|
| 【朗読】の印 | 0.55 | 0.59 | 0.59 | 3つとも明確に低い。付けない |
| 睡眠・寝落ち | 0.63 | 0.52 | 0.52 | 作品名で探される場面では低い |
| 朗読者名（朗読：〇〇） | 1.21 | 1.14 | 1.46 | 小さなチャンネルほど有利 |
| 全文・完全版 | 0.68 | 0.61 | 0.51 | 小さなチャンネルでは低い |
| 複数作品（〇〇集など） | 1.42 | 1.16 | 0.96 | はっきりしない |
| 作業用・BGM | 1.07 | 0.87 | 0.86 | 差はない |
| 『』かぎかっこ | 0.82 | 0.71 | 0.86 | わずかに低い |
| 教科書・学校 | 1.42 | 0.74 | 0.89 | 本数が少なく判断できない |
| 作者名 | 0.25 | 0.18 | 0.16 | 見かけの差（下記） |

作者名を入れていない動画は29本だけで、その上位は俳優・声優の朗読や自治体の宣伝動画だった。作者名を入れると不利という意味ではない。

【朗読】の印が不利な理由は、この分析からは断定できない。考えられるのは、(1) 一覧で最初に目に入る位置を、作品名ではなく誰でも付ける印に使っている、(2) 印を付けるのは小さな個人チャンネルに多い、の2つである。後者は登録者数でそろえても残っていた。

## 6　限界

- 検索結果はその時点の YouTube の並び順に左右される。全数ではない
- 相関であって因果ではない。登録者数と作品はそろえたが、声の質、投稿の時期、チャンネルの本数などは取り除けていない
- コメントはいいねの多い上位のもののみ。分類は言葉の一致による機械的なもので、目で確かめた代表例を併記した
- ウィキペディアの閲覧数は知名度の目安で、朗読の需要そのものではない。記事名が別の意味と重なる作品（人間椅子など）は値が不正確
- 投稿日は498本中【N】本で取得できた。1日あたり再生の比較はその範囲に限る
