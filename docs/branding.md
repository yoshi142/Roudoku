# ブランド方針（案）

Ver.1.0　作成日：2026-10-22　作成：AI　決定は本人

## 1　何を売りにするか

“本人の声” が商品。AI は台本、整音、動画化、説明文を担い、声だけは本物、という線を最初から明示する。説明文には毎回「声は本人の実録音。AI は台本と整音を支援」と書く。これは誠実さの表明であると同時に、AI 生成音声があふれる中での差別化になる。

三つのジャンルは別々に見えるが、聞き手にとっては「落ち着いた声で、信頼できる出典に基づいて、ゆっくり語る」という一つの体験にそろえる。

推奨は「声でよむ」。副題を付けて「声でよむ｜朗読・宇宙・AI」とすればジャンルが伝わる。朗読者名は出さない（本人の決定、2026-10-23）。

## 3　見た目のそろえ方（Ver.2.0、2026-10-23 改訂）

旧版（紺地に細い明朝の縦書き、金の罫線）は、本人の評価「魅力を感じない」と調査結果（docs/thumbnail-research.md）を受けて廃止した。旧版は縮めると題名が読めず、明暗の差が伸びている動画の約4分の1しかなかった。

新しい型（tools/make_thumbnail_v2.py、試作は docs/thumbnail/）
- 作品名を極太の明朝（Zen Old Mincho Black）で、横書き、画面の横幅の6〜8割
- 背景は人の手で作られたものに限る：本人の写真 ＞ パブリックドメイン／CC0 の版画・写真 ＞ 背景なし。AI 生成画像は使わない
- 下に「朱色の短い縦線＋作者名（と作品名）」。朗読者名は入れない（本人の決定、2026-10-23）
- 暗い背景には白文字と黒い縁、明るい紙の背景には黒文字
- 作ったら必ず縮小版（--preview）で題名が読めるかを確かめる
- ジャンルは背景の題材で区別する（朗読＝版画や季節の写真、宇宙＝NASA などのパブリックドメインの天体写真、AI＝本人の机まわりの写真など）。差し色は朱 #c8372d で共通

タイトル（文字列）の書式（Ver.2.1、2026-10-23 の分析 docs/analysis/report.md による）：「作品名　作者名｜朗読」（例：蜘蛛の糸　芥川龍之介｜朗読）
- 「【朗読】」で始めない（規模をそろえても再生が約0.55〜0.6倍）
- 単品の動画に「睡眠・寝落ち」「全文」「完全版」を入れない（いずれも不利）
- 朗読者名は入れない（本人の決定、2026-10-23）。分析では小さなチャンネルで朗読者名ありが約1.5倍だったが、相関であり、俳優・声優など名前で選ばれる人の動画が含まれている
- 長いまとめ版の言葉（用途や分数）は、公開後に YouTube の「テストと比較」で確かめる
- 誰にでも書ける形容（「心に響く」「癒しのひととき」など）は使わない

サムネイルの明るさ（同じ分析による）：暗い画面ほど再生が少なく、白い太字の面積が多いほど多かった。暗い部分は画面の2割程度までにする（tools/make_thumbnail_v2.py の --bg_bright と --veil で調整）。

## 4　公開の計画（案）

- 1本目（雨ニモマケズ、約4分）は “試し” として公開するか、限定公開で確認だけにするかを本人が決める。限定公開でも、録音から公開までの手順の確認はできる
- 手順が回ることを確かめたら、週1本を目安に、朗読→宇宙→AI の順で回す。3本で一巡
- 朗読は短い詩と10分台の童話を交互に。短い詩は制作が軽く、本数を稼げる
- 公開日時を固定する（例：土曜の朝）。聞く習慣ができやすい
