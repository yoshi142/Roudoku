1. 全回の publish.md のタイトルを新しい書式にそろえる：「作品名　作者名｜朗読 本人の名前」。「【朗読】」で始めない。単品に「睡眠・寝落ち」「全文」を入れない。誰にでも書ける形容を使わない（trial-01 は改訂済み、docs/branding.md の3章）
2. サムネイルを全回 v2 で作り直す。暗い部分は画面の2割程度まで、白い太字を大きく、色数を絞る（--bg_bright 0.9、--veil 0.6 前後）。背景は人の手のもの（本人の写真、CC0 の版画・写真）に限り、出典を tools/backgrounds/README.md に書く
3. 夢十夜の台本を作る（第一夜〜第十夜を一夜ずつ。tools/aozora_script.py）。narration/catalog.md の「録る順番」で2番目
4. 長いまとめ版の設計：録った作品をまとめた30分〜1時間以上の版（例：宮沢賢治の詩と短い童話）。チャプター必須
5. 本人の録音が届いたら、tools/README.md の手順で整音、動画化、文面の仕上げ、log.md の記入（最初は trial-01 雨ニモマケズ）
6. 説明文に、確認できた教科書の掲載（docs/research/data/textbook_works.csv）と背景画像の出典を書く
7. 月に1回、tools/yt_research.py と tools/yt_innertube.py で調査を更新する

## 4　本人にしか決められないこと（作業を止めずに、任意の確認として尋ねる）

- 朗読者として出す名前（本名か通称）。サムネイルと説明文の「朗読　〇〇〇〇」に入る
- チャンネル名（仮「声でよむ」）
- 録音（機材、日時）。ボイジャー回は 2026-11-18 の前に公開するのが望ましいので、録音を早めにお願いしたい
- 古典の冒頭（枕草子、平家物語、徒然草、おくのほそ道）を扱うか。需要は大きいが、青空文庫に原文の図書カードがない（方丈記を除く）ので、著作権の確認方法を決める必要がある
- 台本済みの「手袋を買いに」「野ばら」「形」は、分析では小さなチャンネルで見られにくい作品だった。録る順番を後ろにしてよいか
- 本人が撮った写真をサムネイルに使うかどうか（窓の雨、原稿と手元、季節の景色など。AI 臭さを消すうえで効果が大きい）

## 5　注意点（作業環境）

- 作業環境は毎回作り直される。tools/fonts/ は Git に入れていないので、最初に tools/fetch_fonts.sh を実行する
- YouTube の詳細取得は回数制限（HTTP 429）にかかりやすい。検索結果の一覧取得は通りやすい。サムネイル画像（i.ytimg.com）は取得できる
- Wikimedia Commons の API は回数制限が厳しい。メトロポリタン美術館の検索は /public/collection/v1.1/search を使う（旧 /v1/search は 2026-10-01 に廃止）
- シカゴ美術館の API はこの環境から 403
- GitHub の raw ファイルや Google Fonts の直接取得は通らない。フォントは cdn.jsdelivr.net/gh/google/fonts から取得できる
