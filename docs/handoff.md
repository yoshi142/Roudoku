## 1　依頼（次のセッションで行うこと）

本人から別の指示がなければ、上から順に進める。許可を取らずに作り、区切りごとにコミットとプッシュをする。本人にしか決められないことは、作業を止めずに最後に「任意の確認」として一言添える。

1. サムネイルを全回 v2 の型で作り直す（trial-03〜trial-11、背景探しを含む）
   - 型と決まりは docs/thumbnail-research.md の5章と6章、docs/branding.md の3章
   - 背景はメトロポリタン美術館 Open Access（CC0）の版画や、NASA などのパブリックドメイン画像から、作品ごとに合うものを探す。出典を tools/backgrounds/README.md に追記する
   - 蜘蛛の糸は、権利のはっきりした蜘蛛の巣の写真が見つかれば差し替える（現状は文字中心の案）
   - ボイジャー回（trial-03-space）は NASA の画像（パブリックドメイン）を使える
   - 作ったら縮小版で題名が読めるかを必ず確かめ、docs/thumbnail/ に縮小した試作を置く
2. 全回の publish.md のタイトルと説明文を新しい書式にそろえ、AI 臭さを点検する
   - 書式：「『作品名』作：作者名　朗読：本人の名前｜長さや用途」
   - 例：trial-01 のタイトル案「手帳に残された祈りの詩」「落ち着いた声で聞く4分」のような、誰にでも書ける言い回しを具体的な言葉に置き換える
   - 説明文に背景画像の出典（例：背景 歌川広重「庄野 白雨」メトロポリタン美術館所蔵、パブリックドメイン）を加える
3. 本人の録音が届いたら、tools/README.md の手順で整音、動画化、文面の仕上げ、log.md の記入を行う（最初は trial-01 雨ニモマケズ）
4. 次の題材の台本を作る（narration/catalog.md の「次の候補」から。ごん狐、トロッコ、注文の多い料理店、夢十夜 第一夜 など）。tools/aozora_script.py で作り、サムネイルも v2 で用意する
5. チャンネル開設の準備（チャンネル名は仮に「声でよむ」）：アイコンとバナーを v2 と同じ型で作る
6. 月に1回、tools/yt_research.py で伸びている朗読動画の調査を更新し、docs/thumbnail-research.md に追記する

## 5　注意点（作業環境）

- 作業環境は毎回作り直される。tools/fonts/ は Git に入れていないので、最初に tools/fetch_fonts.sh を実行する
- YouTube の詳細取得は回数制限（HTTP 429）にかかりやすい。検索結果の一覧取得は通りやすい。サムネイル画像（i.ytimg.com）は取得できる
- Wikimedia Commons の API は回数制限が厳しい。メトロポリタン美術館の検索は /public/collection/v1.1/search を使う（旧 /v1/search は 2026-10-01 に廃止）
- シカゴ美術館の API はこの環境から 403
- GitHub の raw ファイルや Google Fonts の直接取得は通らない。フォントは cdn.jsdelivr.net/gh/google/fonts から取得できる
