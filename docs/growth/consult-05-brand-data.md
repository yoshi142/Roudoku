# 肩書き・チャンネル名・用途の表示と再生の関係（ブランディングのデータ検証）

Ver.1.0　作成日：2026-10-23　担当：コンサルチーム（ブランディング・データ）

検証した仮説（本人の意見）：「アナウンサー、ナレーター、声優などの権威性や肩書きが、インプレッションに大きく影響しているのではないか。このチャンネルもそれを仄めかしたほうがよいのではないか（例：「ナレーションの世界」）。一方で、高級なブランディングがよいとは限らず、勉強・睡眠導入・作業用に割り切ったほうがよいかもしれない」

前提：docs/analysis/report.md（以下「前回の分析」）［1］、docs/growth/consult-02-data.md（以下「consult-02」）［2］。本人の意見であることは判断に加えず、データが示すとおりに書く。

## 1　要点

1. インプレッション（表示回数）とクリック率は、チャンネルの持ち主が YouTube Studio で見られるだけで、他のチャンネルの分は外から取れない。この文書で見られるのは “再生数” だけで、インプレッションについては、どの部分も「分からない」。
2. 肩書きの手がかり（アナウンサー、元NHK、ナレーター、声優、俳優、朗読家、劇団、公式など）が題名かチャンネル名にある動画は、何もそろえずに比べると再生が約2.6倍だった。ただしその多くはチャンネルの登録者の差で、規模・作品・長さ・投稿からの年数をそろえると1.25倍（95％信頼区間 0.79〜1.99）になり、知名度のある人（テレビ局のアナウンサー、テレビアニメの声優、登録者10万人以上のチャンネルなど）を除くと1.00倍（0.69〜1.44）だった。“肩書きそのものが再生を大きく押し上げている” という形は、データからは出てこなかった。
3. 例外は、登録者1万人未満のチャンネルが投稿3年以内に出した動画で、“題名に” 声の職業を書いたもの（40本、17チャンネル）。規模などをそろえて約2.2倍（1.22〜4.10）だった。一方、“チャンネル名に” 声の職業を入れたもの（14本、7チャンネル）は0.56倍（0.28〜1.09）で、有利な傾向は見えなかった。また、職業を説明欄にだけ書き、題名とチャンネル名には出していないチャンネルの動画も1.38倍（0.96〜2.00）で、名乗った場合（1.19倍）と差がなかった。“名乗ったから見られた” のか “実際に声の仕事をしている人の朗読だから見られた” のかは、区別できない。
4. 仄めかし（職業を名乗らずに「ナレーション」「Voice」「声の〇〇」のような語で連想させる名前）は、該当が朗読中心のチャンネルで25、検索に出た動画で105本（34チャンネル）しかなく、効果は「分からない」。なお「ナレーションの世界 朗読」で検索すると、上位40件のうち9件が【公式】窪田等の世界（登録者30万人）だった［6］。
5. チャンネル名の型（用途、雰囲気・文芸、個人名、肩書き・権威、その他）で、はっきり成績のよい型はなかった。肩書き・権威の名前のチャンネルは、本数と年数をそろえると登録者が約2.3倍（1.16〜4.44、知名度のある人を除くと1.76倍、0.96〜3.26）多かったが、直近の動画の再生は登録者の割に多くなかった（0.84倍）。開設3年以内のチャンネルでは、どの型も登録者の中央値が29〜66人で、差は見えない。
6. 用途の言葉（睡眠、寝落ち、作業用、BGM、勉強など）を題名に入れた動画は、作品名の検索に出てくる動画の中では、長い版（60分以上）に限っても不利なままだった（0.58倍、0.23〜1.46。登録者1万人未満では0.32倍、0.10〜1.08）。長い版にすれば用途の言葉が有利になる、という結果は出なかった。ただし信頼区間は広い。
7. 用途で探す場面（「朗読 睡眠」「朗読 寝落ち」「朗読 作業用」の検索結果101本）は、23チャンネルで占められ、登録者が分かるチャンネルの中央値は約11.6万人だった。半数以上（54％）の動画が肩書きを題名かチャンネル名に出していた。上位の眠り向けチャンネルは “肩書き” と “用途” を両方名乗っている例が多く、“高級か用途特化か” は二者択一になっていない。

## 3　結果

### 3-1　肩書き・権威の手がかり（問1）

まず、何もそろえない比較では差が大きい。肩書きの手がかりがある動画（331本、91チャンネル）の再生の中央値は3,015回、ない動画は881回だった。ただし、手がかりのある動画のチャンネルは登録者の中央値が13,100人、ない動画は1,280人で、規模が10倍違う。

作品・長さ・投稿からの年数だけをそろえた倍率と、登録者数もそろえた倍率

| 範囲 | 登録者をそろえない | 登録者もそろえる |
|------|------|------|
| 全体（2,020本） | 2.60倍（1.13〜6.03） | 1.25倍（0.79〜1.99） |
| 全体から知名度のある人を除く（1,725本） | 1.41倍（0.96〜2.08） | 1.00倍（0.69〜1.44） |
| 登録者1万人未満・投稿3年以内・知名度のある人を除く（718本） | 1.90倍（1.12〜3.20） | 1.58倍（0.96〜2.59） |

全体の差の大部分は、肩書きを出しているチャンネルが大きいこと、とくに知名度のある人の動画（295本、65チャンネル）によるものだった。知名度のある人を除き、規模をそろえると、差はなくなった。

見えたこと
- 統計的にはっきりしたのは、登録者1万人未満・投稿3年以内の “題名に声の職業” だけだった（2.24倍）。中央値で見ると414回と124回、1,000回を超えた割合は28％と16％。チャンネルを1つずつ抜いて計算し直しても1.77〜2.25倍の範囲に収まり、特定の1チャンネルだけによる結果ではなかった
- ただし本数は40本（17チャンネル）と少ない。この文書では40余りの倍率を計算しており、そのうち1つがたまたま大きく出る可能性もある。確かさは “弱い” と見るのが妥当である
- “チャンネル名に” 声の職業を入れた動画は、どの範囲でも1倍を下回った（0.56〜0.74倍、いずれも統計的な差なし）。小さなチャンネルの例は「おやすみ朗読ラウンジ【緒方桃子】フリーアナウンサー」（438人）、「元NHKアナウンサーによる添い寝・寝落ち向け朗読「SOINEOCHI」」（75人）、「フリーアナウンサー竹田りえの朗読チャンネル」（172人）、「小林志保 - 声優チャンネル」（29人）などで、肩書きをチャンネル名に掲げても再生は数十〜数百回のものが多い
- 所属・公式（劇団、公式、協会など）は1.2〜1.5倍で、統計的な差はなかった。この区分には「松江観光公式チャンネル」のような自治体・観光の公式も入っており、朗読者の権威とは性格が違う
- 説明欄だけに職業を書くチャンネルの動画（登録者1万人未満、154本、66チャンネル）は1.38倍（0.96〜2.00）で、題名かチャンネル名で名乗った動画（1.19倍、0.75〜1.90）と同じ程度だった。見る人の目に入る場所で名乗っているかどうかより、“実際に声の仕事をしている人かどうか” のほうが再生と結びついている可能性がある。ただしこれも相関で、説明欄の語には「声優を目指して」のような名乗りでないものも混ざる

まとめると、“規模の大きいチャンネルや知名度のある人の朗読がよく見られている” ことは確かだが、“小さなチャンネルが肩書きを名乗るだけで見られるようになる” ことを示すデータはない。小さなチャンネルが題名に職業を書いた動画が多めに見られている傾向はあるが、本数が少なく、名乗りの効果と朗読の質の差を分けられない。

重なりを許した集計（名前にその要素を含むかどうか、中央値）：声の職業を含む18チャンネルは登録者734人、1本あたり11.6人で、含まない496チャンネル（267人、3.4人）より多かった。用途を含む60チャンネルは141人（含まないもの293人）、雰囲気・文芸の語を含む189チャンネルは316人（同255人）だった。

見えたこと
- 肩書き・権威の型は、登録者が多く、1本あたりの登録者も多い。ただし、直近の動画の再生は登録者の割に多くない（0.84倍、知名度のある人を除くと0.69倍）。“肩書きのあるチャンネルは登録はされているが、新しい動画が登録者数に見合うほど見られてはいない” という形である。もともと仕事で知られた人が、そのつながりで登録を集めている可能性があり、名前の付け方の効果とは読めない
- 雰囲気・文芸の型は、登録者の割に直近の動画の1日あたり再生が多かった（1.82倍）。一方、作品名の検索に出た動画では0.51〜0.67倍で、向きが逆だった。どちらの見方でも一貫した型はなかった
- 用途の型は、開設からの年数が短い（中央値3.6年）。登録者の割に直近の再生がやや多い（1.54倍、境界的）が、開設3年以内で1,000人に届いたのは26チャンネル中1つ（4％）だった
- 開設3年以内では、どの型も登録者の中央値が29〜66人で、1,000人に届いたのは2〜17％だった。名前の型で新しいチャンネルの伸びが変わる、という差は見えなかった
- 仄めかしの語（ナレーション、Voice、ボイス、声の〇〇、声で〇〇、語り、職人、スタジオ など）を含む朗読中心のチャンネルは25で、登録者の中央値368人（含まないもの256人）。数が少なく、比べる材料にならない

- 信頼区間はどれも広く、1をまたぐものが多い。用途の言葉は、それを使うチャンネルがほぼすべての題名に付けるので、実質の比較の単位はチャンネル（60分以上で63チャンネル）になる。前回の分析の0.52倍などは、動画1本ずつを独立に扱った計算で、信頼区間がこれより狭く出ていた。今回のデータでチャンネル単位で計算すると、登録者1万人未満・長さを問わない睡眠・寝落ち系の言葉は0.44倍（0.20〜0.95）だった

- 複数作品をまとめた長い版（題名に「集」「選」「〇作」などがあるもの）は85本しかなく、作品の違いをそろえる余地がほとんどない。倍率は1.58だが、信頼区間が0.42〜5.96で「分からない」

## 4　仮説への答え

| 仮説の部分 | データで言えること | データで言えないこと |
|------|------|------|
| 肩書きがインプレッションに大きく影響している | 肩書きを出した動画は再生が多い（何もそろえずに約2.6倍）。ただしその大部分はチャンネルの規模と知名度のある人で説明され、規模をそろえ知名度のある人を除くと1.00倍（0.69〜1.44）。“大きく影響” は支持されなかった | インプレッション（表示回数）そのもの。YouTube が公開していない。肩書きのある人の朗読が、肩書きのせいで見られているのか、技量や元からの知名度で見られているのか |
| 小さなチャンネルが肩書きを名乗るだけで効果がある | 登録者1万人未満・投稿3年以内で、題名に声の職業を書いた動画は約2.2倍（1.22〜4.10）。チャンネル名に入れた場合は0.56倍（0.28〜1.09）で、有利な傾向はない。説明欄だけで職業を書いた場合も同程度に見られている | 名乗りの効果か朗読の質の差か。本数（40本、17チャンネル）が少なく、確かさは弱い。肩書きが本当かどうかは確かめていない |
| 仄めかしたほうがよい（例：「ナレーションの世界」） | 該当するチャンネル・動画が少なく、効果は「分からない」。チャンネル名に職業を “はっきり書いた” 場合でも、小さなチャンネルでは有利な傾向がなかったので、それより弱い仄めかしに効果を期待する根拠はデータにない。「ナレーションの世界 朗読」の検索では【公式】窪田等の世界（30万人）が上位40件中9件を占め、「〇〇の世界」は大手の名前と並ぶ［6］ | 仄めかしが見る人の印象（信頼、クリック）をどう変えるか。クリック率は外から取れない |
| 高級より用途（勉強・睡眠導入・作業用）に割り切る | 作品名で探される場面では、用途の言葉を題名に入れた動画は、長い版に限っても多く見られていない（60分以上で0.58倍、登録者1万人未満で0.32倍、いずれも信頼区間は1をまたぐか、ぎりぎり）。チャンネル名を用途にした型も、開設3年以内で伸びている様子はない（1,000人以上は26中1） | 用途で探す場面での新しいチャンネルの成績。その検索結果は登録者の多い23チャンネルで占められており、小さなチャンネルの例がほとんどない |
| 高級と用途は対立する | 用途の検索で上位のチャンネルは、肩書きと用途を両方出していることが多い（54％が肩書きあり）。データの上では二者択一になっていない | どちらの打ち出しが、このチャンネルにとって登録につながるか |

補足
- “肩書きのあるチャンネルは登録者が多い” ことと、“肩書きを付ければ登録者が増える” ことは別である。前者はデータにあり（本数と年数をそろえて約2.3倍、知名度のある人を除くと1.76倍、0.96〜3.26）、後者を確かめる材料はない。肩書きのチャンネルは、直近の動画の再生が登録者の割に多くなかった（0.84倍）
- 前回の分析で、朗読者名（朗読：〇〇）を題名に入れた動画が小さなチャンネルで1.46倍だった［1］。今回の “題名に声の職業” の2.2倍と同じ向きで、どちらも “誰が読んでいるかを題名で示した動画” が見られている。小さなチャンネルが職業を書いた題名の多くは、名前も一緒に書いていた（「フリーアナウンサー緒方桃子」「語り 山岡ゆり子」など）。名前を出さずに肩書きだけを書いた例は「元NHKアナウンサーによる添い寝・寝落ち向け朗読「SOINEOCHI」」（75人、再生56〜125回）などわずかで、“名前なしの肩書き” の効果を測れる本数はない。本人の決定（朗読者名を出さない）［7］と、肩書きの表示とがどう両立するかは、データでは判断できない
- 肩書きの語を使うかどうかは、データとは別に、本人の経歴に当てはまるかどうかで決まる。当てはまらない職業を連想させる名前は、見る人の受け取り方によっては誤解を招く。どう受け取られるかを測るデータはない
- 実際に試すなら、YouTube Studio の「テストと比較」はサムネイルと題名の比較に使える。チャンネル名は比較できないので、題名の側で、同じ動画の “用途の言葉あり／なし” を比べるのが、このチャンネル自身のデータを得る方法になる

## 5　限界

- 再生数で見ており、インプレッション（表示回数）とクリック率は見ていない。仮説の「インプレッション」には直接答えられない
- 相関であって因果ではない。登録者数、作品、長さ、投稿からの年数はそろえたが、声の質、読みの技量、サムネイル、投稿の本数と頻度、元からの知名度はそろえていない。肩書きのある人は技量が高い可能性があり、肩書きの効果と区別できない
- 肩書きは自己申告の文字列で、本当かどうかは確かめていない。「静かな男性ナレーターの朗読」のように、職業の名乗りではなく声の説明として使われた語も混ざる
- 知名度のある人の一覧は、検索結果を目で見て作った。漏れがあれば、その人の動画は “知名度なし” の側に入っている
- チャンネル名の型は、ルールと手作業による。境界の例（「佐藤くみこのおやすみ朗読」は用途か個人名か、など）は優先順で決めたので、別の分け方では数字が変わる
- 検索結果は2026-10-23時点の並びで、全数ではない。見られなかった古い動画は上位から外れやすい（生き残りの偏り）。投稿からの年数は「〇年前」の表示からの概算
- 登録者数は今の値で、動画を出した時点の値ではない
- 「直近3年の動画の再生」は、チャンネルの新しい動画一覧（最大30本）から取ったもので、朗読以外の動画も含む。投稿の多いチャンネルでは数か月以内の動画だけになり、再生がまだ少ない
- 用途の言葉はチャンネル単位の習慣なので、実質の比較の数はチャンネル数（60分以上で63）で、信頼区間が広い
- 40余りの倍率を計算したので、たまたま大きく出たものが含まれうる。統計的にはっきりしたものも、1つだけで判断しない
- 用途で探す場面のデータ（101本）は、別の調査で取ったもので、登録者が分かるのは23チャンネル中10チャンネルだけだった
