# 国語教科書 掲載状況の出典メモ

作成日：2026-10-23（閲覧日はすべて 2026-10-23）
対象データ：`docs/research/data/textbook_works.csv`

## 1. 調べた範囲と方法

- 現行版の対象
  - 小学校：令和6年度版（光村図書・東京書籍・教育出版の3社。令和6年度版の小学校国語はこの3社）
  - 中学校：令和7年度版（東京書籍・三省堂・教育出版・光村図書の4社）
  - 高等学校：言語文化・現代の国語は令和8年度用の改訂版（令和6年度検定）、文学国語は現行版（令和3年度検定、令和5年度から使用）
- 主な根拠は、出版社の公式資料（出典一覧・単元一覧・年間指導計画・目次）、文部科学省が公開する編修趣意書、東京都教育委員会の教科書調査研究資料。
- 定番教材かどうかは、光村図書「教科書クロニクル」（過去の版の教材一覧）と、大学紀要・博士論文などで確認できた範囲で判断した。確認できなければ「不明」にした。
- 検索エンジンの要約だけで済ませたものは、下の表で「検索要約のみ」と書いた。

## 2. CSV の列の読み方

- current_level：小・中・高のどこで現行版に載っているか。複数の校種にまたがる作品は「小;中;高」のように「;」で区切った。
- current_level が「不明」の作品は、次の意味で使っている。
  - 小学校3社・中学校4社の現行版の一覧（全社分）には載っていない。
  - 高校は、言語文化17冊と文学国語10冊の資料で見つからなかった。ただし編修趣意書は全教材を網羅するとは限らず、確認できていない教科書もある（5章）。
  - そのため「なし」とは書かなかった。分析で使うときは「現行教科書で習う可能性は低い」と読んでよいが、断定はできない。
- classic_textbook：長く載っている（定番）と資料で確認できた場合だけ「はい」にした。いまの版に載っていても、長期の掲載を示す資料がなければ「不明」にした。

### 3-5. 参考にしたが根拠にしなかったもの（出典の確からしさ：低）

- 教科書の掲載作品を紹介するブログ・まとめ記事（kyoukasyo.com、個人ブログなど）。判定の根拠には使っていない。
- 「かつて小学校の国語教科書に収められていた」とする一般書の紹介文（野ばら、雨ニモマケズ）。社・学年・時期が書かれていないので、classic_textbook は「不明」のままにした。

## 5. 判断に迷った点・限界

- 光村図書の公式サイト（www.mitsumura-tosho.co.jp）は閲覧日にメンテナンス中（HTTP 503）で、教科書クロニクルは検索結果の要約でしか確認できていない。web.archive.org はこの環境から使えなかった。
- 光村の出典一覧 PDF では学年の見出しがセルの中央に置かれていて、「ごんぎつね」が4年上か4年下かは決められなかった。「小4」とだけ書いた。小5・小6の区切りは見出しの位置とページ区切りから判断した。
- 「手ぶくろを買いに」（光村4年）は出典一覧に載っているが、本文教材か、読書・発展の扱いかは確認できていない。
- 東京都の調査研究資料の「文学的な文章」一覧には、読書教材や作品紹介も含まれているらしい。例として、三省堂中3に「走れメロス」がもう一度出てくる。教出中2の「坊っちゃん」は〈読書〉教材だと趣意書で確認できた。「銀河鉄道の夜」「よだかの星」「吾輩は猫である」は本文か抜粋か紹介かを確かめていないので、confidence を中にした。
- 三好達治「雪」は作者名と題名から「太郎を眠らせ」の詩と判断した。本文は見ていない。
- 萩原朔太郎「竹」は同じ題の詩が複数あり、教科書のものが「光る地面に竹が生え」かは未確認。
- 高校で確認できていない教科書：
  - 言語文化：数研出版104-903、大修館050-902（趣意書の文字化け）、旧版で令和8年度にも使われている文英堂710・第一学習社713/715/716
  - 文学国語：数研出版706（趣意書の文字を取り出せなかった）
  - 三省堂などの「新」付き科目の版は、科目一覧の範囲外の可能性がある
  - 編修趣意書は教材をすべて載せるとは限らない
- 文学国語は令和9年度（2027年4月）から新しい版に切り替わる。CSV の文学国語の記述は 2026年度時点の現行版にもとづく。大修館の改訂版目次では山月記・こころ・舞姫・檸檬・永訣の朝・竹が継続していることを確認した。
- 小学校で教育出版は、令和6年度版の小5で「雪わたり」（宮沢賢治）を採用している。熊本市の会議録で触れられていた「注文の多い料理店」は旧版のことと考え、現行の掲載社には入れなかった。
